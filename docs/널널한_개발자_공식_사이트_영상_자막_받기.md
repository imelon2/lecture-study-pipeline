# 널널한 개발자 공식 사이트 영상·자막 받기

공식 사이트(nullnull.co.kr) 강의는 로그인 후 재생되어 `summarize`로 바로 추출되지 않습니다. 영상(`mp4`)과 자막(`srt`)을 CLI로 받는 방법입니다. 수강 중인 강의를 개인 복습용으로만 사용하고, 이용약관을 먼저 확인하세요.

## 0. 준비

- 시스템 도구: `ffmpeg`, `whisper-cpp` (`whisper-cli`)
- 전사 모델: `ggml-large-v3-turbo-q5_0.bin` (약 574MB)

```bash
brew install ffmpeg whisper-cpp
mkdir -p ~/.cache/whisper-cpp
curl -L -o ~/.cache/whisper-cpp/ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
```

## 1. m3u8 주소 찾기

1. 로그인 후 강의 페이지(`.../courses/<코스>/learn?lectureId=<번호>`)를 엽니다.
2. 개발자도구(`Cmd+Option+I`) → **Network** 탭 → 필터에 `m3u8` 입력.
3. 페이지를 새로고침하고 영상을 재생합니다.
4. `output_1080p.m3u8?Policy=...` 요청을 우클릭 → **Copy → Copy URL**.
5. 안 보이면 필터를 `mp4`, `mpd`, `.ts`로 바꿉니다.

`<video src="blob:...">` 주소는 임시 주소라 쓸 수 없습니다. 복사한 URL의 `Policy`·`Signature`는 만료되는 토큰이므로 바로 사용하고, 공유·커밋하지 않습니다.

## 2. 영상 다운로드

`ffmpeg`에 URL을 바로 넣으면 `.ts` 조각 주소에 서명이 빠져 실패합니다. 조각마다 서명을 붙인 재생목록을 만듭니다.

복사한 URL을 두 부분으로 나눕니다.

- 폴더 주소: `output_1080p.m3u8` 앞까지 (`.../hls`)
- 쿼리: `?` 뒤 전체 (`Policy=...&Signature=...&Key-Pair-Id=...`)

예시 (`AAA`, `BBB`, `CCC`는 복사한 URL의 실제 값으로 바꿉니다):

```
https://cdn.nullnull.co.kr/protected-content/videos/533/hls/output_1080p.m3u8?Policy=AAA&Signature=BBB&Key-Pair-Id=CCC
```

```bash
cd "$(mktemp -d)"                  # 작업 폴더 (저장소 밖)

# 1. 재생목록 받기: 복사한 URL 전체
curl -s -o pl.m3u8 'https://cdn.nullnull.co.kr/protected-content/videos/533/hls/output_1080p.m3u8?Policy=AAA&Signature=BBB&Key-Pair-Id=CCC'

# 2. 조각 주소에 서명 붙이기: "폴더 주소/" + $0 + "?쿼리"
awk '/\.ts$/ {print "https://cdn.nullnull.co.kr/protected-content/videos/533/hls/" $0 "?Policy=AAA&Signature=BBB&Key-Pair-Id=CCC"; next} {print}' pl.m3u8 > signed.m3u8

# 3. 확인: pl.m3u8 첫 줄은 #EXTM3U, signed.m3u8 조각 줄은 .../hls/output_1080p_00000.ts?Policy=... 형태여야 합니다
head -3 pl.m3u8
head -8 signed.m3u8

# 4. 영상 합치기
ffmpeg -protocol_whitelist file,https,tcp,tls,crypto -allowed_extensions ALL -extension_picky 0 \
  -i signed.m3u8 -c copy lecture.mp4
```

주의:

- 2번의 `"...hls/"` 끝에 `/`가 있어야 하고, `" $0 "?`에서 `$0`과 `?`는 그대로 둡니다.
- 403 오류는 주소를 잘못 만들었거나 URL이 만료된 경우입니다. 만료되면 1단계에서 URL을 다시 복사합니다.

`#EXT-X-KEY` 줄이 있으면 암호화된 영상이므로 여기서 중단합니다.

## 3. 자막 추출

영상에 자막이 없어 음성을 전사합니다.

```bash
ffmpeg -i lecture.mp4 -ar 16000 -ac 1 a.wav
whisper-cli -m ~/.cache/whisper-cpp/ggml-large-v3-turbo-q5_0.bin -l ko -f a.wav -osrt -of lecture
```

결과는 `lecture.mp4`(영상)와 `lecture.srt`(자막)입니다. 전사 결과이므로 용어 오인식이 있을 수 있습니다.
